# Güvenlik ve gizlilik

Bu repo **hiçbir kurulum komutunu otomatik çalıştırmaz**. README'deki komutlar yalnızca örnektir; komutu çalıştıran kullanıcı, üçüncü taraf kaynaktan dosya veya çalıştırılabilir kod alabilir.

## Yüklemeden önce

1. Kurulacak paketin geliştiricisini ve güncel kaynak adresini doğrulayın.
2. `npx` ve plugin kurulumlarının sağlayabileceği yürütme yetkilerini değerlendirin; şüpheli paketleri çalıştırmayın.
3. Claude Code hook'larının hangi dosyalara erişebildiğini kontrol edin.
4. Hafıza araçlarında sohbet kayıtlarının ve dosya içeriklerinin nereye yazıldığını, ne kadar tutulduğunu ve üçüncü taraf servise aktarılıp aktarılmadığını araştırın.
5. `.env`, anahtar, erişim belirteci, kişisel bilgi ve müşteri verilerini açık GitHub depolarına göndermeyin.

Bu depoda bir güvenlik sorunu görürseniz gizli anahtar veya kişisel veriyi public issue içine yazmayın. Önce içeriği depodan uzaklaştırıp ilgili erişim anahtarını iptal edin.
